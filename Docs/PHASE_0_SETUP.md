# Phase 0 — Reproducible Project Foundation

## Goal

Establish a new, isolated, openable Unity project and verify the webcam path **before** pose-estimation or anatomy integration. Existing `OpenPosePlugin/` remains untouched.

## Baseline

- Unity Editor: **6000.3.27f2** (6.3 LTS, fixed security patch as of 2026-11-06).
- Initial platform: **Windows desktop** for the existing OpenPose lineage. macOS desktop is a secondary manual smoke-test target.
- Unity UI: uGUI package 2.0.0 for Phase 0, with no MediaPipe/OpenPose dependency.
- Package lock: generated by Unity on first successful import; commit `packages-lock.json` afterwards.
- Hardware: one working webcam and permission for the Unity Editor to access it.
- Rendering: stock Unity scene for Phase 0; **URP not yet configured**. Add an actual URP template/config in a later dedicated change.

## Reproducible local setup

1. Install Unity Hub and exact editor version shown in `Unity/ProjectSettings/ProjectVersion.txt`.
2. Clone the repository, then check out `feature/magicmirror-2.0-foundation`.
3. Open the folder `Unity/` in Unity Hub as the Unity project.
4. Wait for Package Manager import and C# compilation. Investigate Console errors before proceeding.
5. Choose **MagicMirror > Phase 0 > Create Camera Test Scene** from the editor menu. This will create and save `Assets/Scenes/Phase0CameraPreview.unity` and place the scene in Build Settings.
6. Press **Play**. Approve operating-system permission if prompted.
7. Confirm the `Camera:` status, mirrored video, and stable preview. If no camera is available, a descriptive status should appear instead.
8. Exit Play mode; save the scene and commit the generated `.unity`, `.meta`, `packages-lock.json`, and any additional necessary Unity project settings.

## Acceptance checklist (requires a real Unity Editor run)

- [ ] Unity project opens with 6000.3.27f2 and no C# compile errors.
- [ ] Scene-generation menu item runs and writes `Assets/Scenes/Phase0CameraPreview.unity`.
- [ ] Webcam preview appears when Play mode starts.
- [ ] Mirrored left-right movement looks correct.
- [ ] Missing/unavailable webcam produces a readable message, not a crash.
- [ ] Leaving Play mode stops the webcam stream.
- [ ] Unity scene and generated metadata are committed.
- [ ] Re-clone into a clean folder and repeat the test successfully.
- [ ] Record OS, hardware, camera, observed FPS and any limitations.

**Current checkpoint:** source scaffold committed; above runtime checks must be performed in the Unity Editor. Do not mark Phase 0 complete before they pass.

## macOS privacy note

If the webcam cannot start, inspect macOS Settings > Privacy & Security > Camera and grant the Unity Editor permission. Do not try to bypass operating-system privacy controls.
